# Pre-push review, 0.3.1.0

The pattern table shipped in 0.3.0.0 was measured against real channel content
and scored zero. This release records that and changes nothing else.

## Findings

**F23 to F27.** In `docs/METHODOLOGY.md` with their classes. Summary: the area
table matched 0 of 20 because the channel names raions and hromadas rather than
oblasts; the geographic model needs a gazetteer that does not exist; means of
attack is a separate message class rather than an attribute; a fourth state
exists; and the page is a twenty-message window rather than a stream.
Disposition: all recorded, none fixed. Owners T15 to T18, sprint 5.

**F28. Nothing was tuned in response, deliberately.**
The obvious move was to rewrite the table against these twenty messages and ship
a green hit rate the same afternoon. That would repeat F23 at a smaller scale:
fitting to a twenty-message sample drawn from twenty minutes of one evening, on
one part of the country, is the same error as fitting to reasoning about how the
channel probably words things. The redesign needs a week of content, not a page.
Disposition: accepted as a decision, recorded so it is not mistaken for neglect.

**F29. The measurement is pinned as assertions, not prose.**
Three tests assert the zero hit rate and carry the message "update this pin and
close F23". Fixing F23 therefore requires flipping a pin deliberately. A defect
this large should not be closeable by accident.
Disposition: fixed.

**F30. `lint_domain` failed on a sentence about future work.**
It scraped the changelog for the word "sprint" and demanded a regression file for
every number it found, so writing "the redesign is sprint 5" broke the build.
Shipped is a fact in `STATUS.json`, not a word in prose.
Disposition: fixed. Worth recording: a lint that keys on natural language will
eventually fire on someone writing a sentence.

**F14 remains open, second slip.** The harness has still never been observed
failing. Owner was 0.3.0.0, then 0.3.1.0, and it has not landed either time.
Re-owned to 0.4.0.0 with a note that this is the second slip. A third without a
different owner means it is not going to happen and the claim about the harness
should be weakened instead.

## What the measurement cost and what it bought

Cost: the adapter shipped in 0.3.0.0 parses nothing from live content. A day of
work produced a component that does not do its job.

Bought: the failure is total, visible and located. The area layer is wrong for a
structural reason, not a spelling reason, and that reason implies a missing
dataset nobody had noticed was missing. Discovering this from a fixture would
have been impossible; discovering it after building the decision layer on top
would have been far more expensive.

The design assumption that earned its keep: unparsed messages are counted rather
than dropped. Without that counter the adapter would have reported "no events"
and looked like a quiet channel.
