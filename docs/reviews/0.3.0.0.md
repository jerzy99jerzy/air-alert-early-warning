# Pre-push review, 0.3.0.0

## Findings

**F17. A raising parser is an outage. Fixed.**
`poll` now absorbs every content failure and reports it; only reachability
raises. Six hostile bodies in the unit suite and six more in harness A9.
Disposition: fixed.

**F18. A stale pattern table would look like a quiet channel. Fixed.**
Unmatched messages are counted and printed. `mavo collect` says so explicitly
when the count is non-zero.
Disposition: fixed.

**F19. The pattern table is unverified against live traffic. Accepted, named.**
`AREAS`, `START_MARKERS`, `CLEAR_MARKERS` and `KIND_MARKERS` were written from
reasoning about how the channel plausibly words its messages, not from observed
messages. They are almost certainly wrong in detail.
Disposition: accepted, and deliberately structured so being wrong is visible
rather than silent. The module docstring, the manual and the changelog all say
it. The first live run is a measurement, not a confirmation. Owner: the first
successful `mavo collect` against the real channel.

**F20. The container cannot reach the channel, so the live path is unexercised.
Accepted, named.**
`mavo collect` was probed in both modes. Against the saved page: three messages,
two parsed, one counted as unparsed. Against the network: `403 Forbidden`, exit
3, no traceback. That proves the refusal path and proves nothing about parsing
live HTML.
Disposition: accepted. Trigger: first run from a host that can reach `t.me`.

**F21. The README claim about the network became false. Fixed by the lint.**
`make verify` failed on `no_network_calls` the moment the adapter landed. The
claim was rewritten to the narrower one that is now true and still checkable
(only `transport.py` imports a network client) rather than the check being
weakened.
Disposition: fixed. Worth recording because this is the control working as
designed on its author.

**F22. The sprint-4 regression file is an import-level red. Accepted.**
Against 0.2.1.0 the file errors on collection because the modules do not exist,
rather than failing on behaviour. Weaker evidence than a behavioural red, and
stated in the file's own docstring.
Disposition: accepted, same class as the 0.2.1.0 harness note.

**F14 remains open.** The harness has still never been observed failing. Owner
was 0.3.0.0 and it did not land. Re-owned to 0.3.1.0, before any continuous
collection. Slipping a finding once is a schedule fact; slipping it twice
without renaming the owner is how it becomes permanent.
