# Review 0.47.0.0: twelve rows nothing would ever end

Version: 1.0 / 2026-08-30

The command exists because the map was asserting twelve alarms from a source
that died on 2026-08-29 04:55 UTC, for areas the replacement source had not
mentioned in roughly ninety full-state polls and did not hold in its current
snapshot. `[measured]` means read off `vm-mavo` on 2026-08-30 or executed in
this repository's container.

## 1. What the licence actually is

Not the channel's silence - 28 hours of a dead publisher license nothing - but
the API's presence: a fresh snapshot is a complete claim about the sky at one
moment, and absence from it, after absence from every poll since the
switchover, is a verified negative. The command therefore refuses to run on
anything but a `fresh` snapshot, and the refusal is a printed state, not a
quiet skip.

## 2. What it refuses, and why that is the harder half

`MASKED` rows - snapshot says alerting, newest stored row says otherwise -
are the invariant's own direction: calm rendered during an alarm. Closing has
no business there and the command only names them. The 53-versus-33 gap from
the same reading is unattributed `[unverified]`: ties and per-kind rows can
double-count a census, and the first dry-run prints the population either
way. If it is real, the repair is a decision about the fold's ordering or the
API adapter's re-assertion, minuted before written, and it is the next
decision this project owes itself.

## 3. Retired on a measurement, recorded as one

D-041's parent condition protected against closing raions the API would only
ever name through their oblast. The payload of 2026-08-30 named eight Donetsk
raions individually. The condition is retired in the command and the premise's
falsification is written here rather than deleted, because a guard removed
without its reason recorded is a guard someone will reinstall.
