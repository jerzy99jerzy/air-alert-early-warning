# Pre-push review, 0.2.1.0

Every finding dispositioned: fixed, accepted with reasons, or deferred with an
owner. Convention adopted from `pirx/docs/reviews/`.

## Findings

**F9. The banner was built on a guess. Fixed.**
An animated SVG was produced before `pirx` had been read, on the assumption that
its banner was SVG. It is a GIF. The SVG was deleted rather than kept as an
alternative, because two banners in a tree means one of them is stale.
Disposition: fixed. The lesson is the general one: three questions to the person
who owns the convention would have cost less than the artefact did.

**F10. Version scheme diverged from the portfolio. Fixed.**
Three-segment versioning was chosen without checking. `pirx` uses four segments
with the bump as its own commit. Now four. Earlier tags keep their three-segment
form: renaming a shipped tag defeats the one thing a tag is for.
Disposition: fixed at 0.2.1.0, historical entries left alone.

**F11. Refusals were untyped. Fixed.**
Three call sites raised bare `ValueError`. A caller catching `ValueError` catches
unrelated failures, and a harness asserting on it proves nothing. `mavo/errors.py`
now carries the taxonomy, and deliberately does **not** inherit `ValueError`, so
the four tests that caught the wrong type had to be changed. That breakage is the
control working.
Disposition: fixed.

**F12. The threat model was prose with no test references. Fixed.**
Rows are now MT1 to MT10, each with a control or a named acceptance and the test
that measures it. `tools/docs_audit.py` fails on a numbering gap or a count that
disagrees with `STATUS.json`.
Disposition: fixed.

**F13. No harness. Partially fixed, honestly bounded.**
Eight scripted attacks now exist, one per testable row. They assert returned
values and printed output, where `pirx` asserts that the refusal appears in the
ledger the product wrote. That is a weaker criterion and `CATALOGUE.md` says so.
Disposition: accepted for now. Owner: the version that lands the output channel,
which brings a ledger with it.

**F14. The harness has never been observed failing. Deferred.**
`pirx` verifies its harness by mutation: mutants are introduced into the product
and the harness is watched failing. A verification vehicle that has never failed
is not a measured control. Not done here.
Disposition: deferred. Owner: 0.3.0.0, before any live adapter ships. This is the
most significant outstanding gap in the tree.

**F15. MT7 claims a guarantee it does not measure. Accepted, named.**
The never-raise contract is asserted on the fixture source only, because no live
adapter exists. Stated in the threat model and the catalogue rather than implied
away.
Disposition: accepted. Trigger: the first live adapter, in the same version.

**F16. The Polish project brief is a second source of truth. Deferred.**
`MAVO_projekt_v1.2.md` lives outside the repository and now disagrees with
`docs/` in several places. `pirx` keeps its brief in-tree as
`docs/PIRX-PROJECT-BRIEF.md`.
Disposition: deferred to 0.3.0.0, which folds it into
`docs/MAVO-PROJECT-BRIEF.md` and retires the external file.
