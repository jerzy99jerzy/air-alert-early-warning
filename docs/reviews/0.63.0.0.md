Version: 1.0 / 2026-10-25

Mandated by D-021 on the minor bump. Against `main` at 0.62.0.0. **This release
is the repair half of a review rather than a feature with a review behind it.**
The full review of 0.62.0.0 and `mavo-site` 4.93.0.0 ran on 2026-10-21 and
2026-10-25: seven reviewers read the trees in parallel, each under one rule, a
defect is reported only with a reproduction run in the session and a negative
control beside it, and the lead re-ran every reproduction ranked high or above.
Its report is the operator's `REVIEW-0.62.0.0-4.93.0.0.md`; what follows is
what this release took from it, and what it did not. `[measured]` means
executed in the review's or this release's container.

## 3. A decision taken in the building, for the operator to read

**P-2 and F138.** The review's sketch refused a body if any region record was
unreadable. F138 settled that an unreadable record among readable ones is
counted, not refused, and its test held a body of one unreadable record. That
body, under a fresh snapshot, cleared every open alarm, which is P-2 itself.
The rule built: refuse a body in which **no** record reads; count one among
readable ones as before. F138's test now pins the mixed body, and the
single-garbage body is a refusal.

## 4. What was not built, and where it went

- **A gate on figures in prose** (the review's OPS-13): not built. A check
  that cannot say which sentence states the present and which a dated history
  would fail the CHANGELOG on every count it ever printed, or be tuned until
  it catches nothing. T97 states an acceptance that is buildable: a registry
  of current-state sentences, each recomputed from the tree. D-065's own cost,
  stated as one request more a run where the tree adds two, is corrected in
  this release by hand, which is the class T97 exists for.
- **The RSO cadence** the repository still declares as 900 s: T98, tier 1, now
  with the register consequence the review measured (N-4).
- **The running week on the analysis page** (the operator's epic of
  2026-10-20): T99, a decision between a consumer-only note and a
  `current_week` block in `analysis.json`.
- **Every medium and low finding** of the review: in its Part 6, ordered.
